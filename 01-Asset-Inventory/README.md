# Asset Inventory

This folder contains the IT asset inventory for MedSecure Solutions, a fictional healthcare organization.

The inventory documents critical IT assets, asset owners, data classification, and business impact.

The file would contain below fields

- Asset Inventory: Eight IT assets, including employee laptops, Microsoft 365, electronic health records, cloud storage, and backup systems.
- Professional formatting: Colored headings, structured table, and readable columns.
- Asset classification: Criticality, data classification, asset owner, and business impact.
- Automatic summary: Counts of total, critical, and high-priority assets.
- Dropdown menus: Easily update criticality and data classification.
- Instructions worksheet: Explains how to use the workbook.
